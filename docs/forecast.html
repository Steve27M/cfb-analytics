Predictions on the record

2026 Forecast Scoreboard

On July 1, 2026 — before a single game — this project's preseason model predicted every FBS-vs-FBS game of the 2026 season and froze those predictions in the git history, where they can't be quietly edited. This page scores them against reality all season. The models keep improving; the originals stay untouched — and at the end of the year, they answer for themselves.

✓ Frozen means frozen. Every forecast version is an immutable, SHA-256-manifested directory sealed by a git commit — the commit date proves the predictions predate the games.  ✓ Before-kickoff rule. An updated model is scored only on games played after it was created — no version ever gets credit for a game it could have known the result of.  ✓ Scope. FBS-vs-FBS regular-season games only; games against FCS opponents carry no prediction and don't count for or against any version.
